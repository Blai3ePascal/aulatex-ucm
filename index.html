Tu GitHub, tu espacio


Cada persona utiliza su propio token. Para propietario o miembro de organización: token fine-grained limitado al repositorio con Contents RW + Actions RW (e Issues RW para comentarios y chat). Para leer bastan permisos de lectura. Los colaboradores externos pueden necesitar un token classic con ámbito repo, más amplio: consulta la guía y la política de la organización. No introduzcas tu contraseña de GitHub.








El repositorio debe contener la plantilla repo-proyectos del paquete. Un repositorio por proyecto o grupo con idénticos permisos. Compartir concede acceso a todas sus carpetas. Nunca pegues un token de otra persona, una clave privada de GitHub App ni tu contraseña.


El token no se guarda en cookies, localStorage, IndexedDB, URLs ni archivos. Un token funciona como una llave: úsalo solo en una copia del editor que controles y revises.



Nuevo proyecto
Se creará en memoria. Pulsa Guardar en GitHub para subirlo; sin conexión puedes exportarlo como ZIP.


Importar un proyecto LaTeX
Selecciona el ZIP exportado desde Overleaf o una carpeta LaTeX comprimida. No subas un repositorio completo con .git. Límite: 30 MiB comprimidos, 80 MiB extraídos y 500 archivos.


Versiones guardadas
El historial corresponde a las versiones guardadas en GitHub, no a cada pulsación. Las restauraciones se realizan desde GitHub o importando un ZIP anterior.




Compartir proyecto




El enlace no concede permisos. Primero invita a la persona. Después acepta la invitación y entra con su propio token. El modo «ver» es una comodidad de la interfaz, no una restricción de seguridad.




Invitar desde aquí





No se guarda. Debes ser administrador del repositorio. No necesitas ampliar el token diario de edición: también puedes invitar en la página de GitHub.


Gestionar en GitHub






Conservamos las dos versiones


La sincronización está pausada. No se ha sobrescrito GitHub. Compara, elige una versión o escribe una combinación. Las zonas compatibles ya se han combinado.




Versión común de partida







Una versión eliminada significa borrar el archivo. Después de resolver todos los conflictos, pulsa Guardar. Para combinar dos binarios, descarga ambos y sustituye el archivo manualmente.




Comentarios y tareas


Se guardan como Issues de GitHub, vinculadas al proyecto. No son anotaciones móviles sobre el PDF. La selección y la línea se refieren a la revisión indicada.

Importa, revisa y cita. Tus archivos .bib siguen siendo la fuente de verdad. Nada se añade ni publica sin confirmación.




1. Traer referencias


BibTeX / BibLaTeX, RIS y CSL JSON. En Zotero: Exportar colección → BibLaTeX o CSL JSON. No hace falta una cuenta Zotero.
